# /add-issue コマンド

ユーザーが入力した内容を、このリポジトリの GitHub Issue として登録する。

対象リポジトリは `graph-viz-with-llm`。`gh` はこのリポジトリのルートで実行し、`-R` は付けない。

## 手順

1. ユーザー入力からタイトルを決める。本文の指定があれば `--body` に使い、無ければ空にする。
2. ラベルやマイルストーンの指定があれば、そのまま `gh issue create` に渡す。無ければ付けない。
3. 次を実行する。

```bash
gh issue create --title "ユーザーが入力したタイトル" --body "本文（無ければ空）"
```

4. 作成された Issue の番号と URL を表示する。

## 制約

- 既存の未着手タスクやローカルの作業メモを、頼まれていないのに Issue 化しないこと
- タイトルが曖昧なら、作成前に短い確認をしてから登録すること

## 例

ユーザー入力: `/add-issue ヘルプコマンドを実装する`

実行コマンド:

```bash
gh issue create --title "ヘルプコマンドを実装する" --body ""
```
